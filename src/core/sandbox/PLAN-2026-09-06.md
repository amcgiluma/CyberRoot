### Hito 2 — S1: infraestructura Shell multi-host + host-key (est. 1.5h)
Qué: Extender Shell para hosts simultáneos, fingerprint determinista, prompt host-key

- Intercept yes/no/[fingerprint] cuando pending_ssh != None al inicio de execute() antes de parsing normal: "yes"/fingerprint → cache fingerprint, push stack, connect, mensaje `Warning: Permanently added 'host' ...\nConnected to host.\n`; "no" → no conecta, mensaje `Host key verification failed.` sin ruido, limpiar pending, registrar decisión. Respuesta queda en ssh_decisions.
