### H2 — Wrapper Shell._exec_scp (60m)
- shell.py: importar SCP_NAME, añadir handling en _exec_argv: if argv[0]==SCP_NAME and SCP_NAME in available_commands: return _exec_scp
- Implementar _exec_scp(self, argv, stdin):
  - validar argc==3 (scp SRC DST), sino usage: "scp: missing file operand" o "scp: too many arguments"? Seguir GNU: 2 operandos requeridos. Si <2 → missing, >2 → too many? Pero scp GNU acepta exactly 2 operandos. Hacer checks.
  - parse_host_path(spec): si ":" en spec → hostPart, pathPart. hostPart puede contener "@": host = hostPart.split("@")[-1]. Si host vacío → error Could not resolve. Si no ":" → local path.
  - Detectar caso sin remoto → error "scp: no remote host specified" exit 1 ruido scp (didáctico)
  - Detectar ambos remotos: soportar (copia entre remotos) — permitir, no rechazar.
  - Para cada host remoto: if host not in self.hosts → rechazo didáctico exit 1 ruido 0 con mensaje `scp: host 'X' no descubierto — léelo en /etc/hosts`
  - Resolver FS src/dst: fs_src = hosts[host] si remoto else self.fs ; fs_dst igual. Path_src/path_dst = parte tras ":"
  - Si path_src vacío → error destino inválido
  - Intentar leer src: fs_src.read_file(src_path, "/") si remoto else (self.cwd) — para local usar self.cwd. Si FsError → mapear a `scp: <spec>: No such file or directory` etc, con exit 1 + ruido scp
  - Para dst: determinar si dst es dir existente → destino = join(dst_path, basename(src_path)) ; else destino = dst_path
  - Validar dst parent existe, no is_a_directory, same_file, invalid_argument → mapear a mensajes `scp: <dst>: <msg>` con exit 1 + ruido scp
  - Copiar: crear FileNode con content/mode/owner/group/mtime de src en dst_fs
  - Si dst_fs == self.fs y dst es relativo, resolver con self.cwd; si remoto, con "/"
  - Emitir ruido scp via NoiseMeter().emit y retornar CommandResult(stdout="", exit 0, noise=(emit,))
  - Edge: scp no debe tocar host_stack ni known_hosts
- Criterio: shell.execute("scp ...") funciona en 4 casos, ruido 0 solo en caso no-descubierto
