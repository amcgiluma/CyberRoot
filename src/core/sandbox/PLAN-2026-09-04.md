# PLAN-2026-09-04 — S1 cut en el sandbox (Smough)

## Objetivo
Implementar `cut -d DELIM -f LIST` GNU-honesto para que la pista `cut -d'|' -f4,12 registro.csv | sort | uniq -c` de CENSO-LISTA exista (P2 Havel 03/09). Solo el verbo; la quest queda en recámara.

## Hitos (~1h c/u) + criterio de hecho

### H1 — Handler `cut` core (src/core/sandbox/commands/cut.py)
- **Qué:** `_run_cut(fs,cwd,argv,tick,stdin)` con:
  - parseo de `-d`/`--delimiter=DELIM` (delim single-char; multi-char → error GNU `the delimiter must be a single character` exit 1; sin -d → TAB default)
  - parseo de `-f`/`--fields=LIST` / `--field` etc (sin -f → `you must specify a list...` exit 1; `-f` sin arg → `option requires an argument -- 'f'` exit 1)
  - LIST = coma-separado de rangos `N`, `N-`, `-M`, `N-M` (valida dígitos, N>=1, N<=M; lista vacía/inválida → error)
  - Normalizar LIST a set ordenado (sort+uniq de índices) como GNU ( `4,1` → 1,4)
  - Leer entradas: `_read_input` coherente con conteo.py (stdin o files; múltiples ficheros; errores FS → stderr + exit 1)
  - Por línea: si delim no está → imprimir línea entera; si sí → split por delim, seleccionar índices 1-indexed que existan, join por delim. Línea vacía → vacía. Sin concatenar líneas sin \n final (cada línea con \n si tenía delimitador? GNU conserva \n por línea).
  - Soportar stdin de tubería (cmd1 | cut) via param `stdin`.
- **Interfaces:** CUT_SPEC = CommandSpec(name="cut", concepts={"cut"}, noise=NOISE_PROFILE["cut"], run=_run_cut); exponer SPECS tuple.
- **Edge:** -s / --only-delimited no se implementa v0 (gap documentado).
- **Hecho si:** `cut -d'|' -f4 file`, `cut -d'|' -f4,12`, rangos `1-3`, `2-`, `-2`, línea sin delim intacta, error sin -f, error delim multi-char, stdin, múltiples files, golden contra GNU (ejemplo purgas.csv).
