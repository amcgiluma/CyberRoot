### S1 — `ps`/`env` en el sandbox (`src/core/sandbox/`)

**Frontera importante (ARCHITECTURE §1.5):** el sandbox es CERO RNG. Los
procesos simulados de la sala son PIEL del generador: entran como estado del
FS (`fs.processes`), el sandbox solo los RENDERIZA. Un test nunca debe fabricar
procesos con `random`; la determinista la aporta quien construye el FS (seed del
generador) y el comando la reproduce byte a byte.

**Hito S1.1 — modelo de estado en `fs.py`:**
- Dataclass `Proceso` (frozen): `pid:int, user:str, cmd:str, tty:str="?",
  cpu:str, mem:str, vsz:str, rss:str, stat:str, start:str, time:str`
  (campos para `ps` —cabecera compacta— y `ps aux` —columnas GNU—).
- `FileSystem`: campos nuevos `processes: tuple[Proceso,...]=()` y
  `environment: dict[str,str]` → `to_dict`/`from_dict` ida-y-vuelta EXACTO.
  `from_dict` con `.get()` (backward-compat: un save v0 sin estos campos carga
  con procesos vacíos y env `{}`).
- Ronda la salida: acoplar los golden de FS e idempotencia del roundtrip.

**Hito S1.2 — comando `ps` (`commands/procesos.py`):**
- `ps` (sin flags): cabecera GNU `    PID TTY          TIME CMD` + filas de
  `fs.processes` ordenadas por pid (determinismo §5).
- `ps aux`: cabecera GNU `USER         PID %CPU %MEM    VSZ   RSS TTY      STAT
  START   TIME COMMAND` + filas. Columnas —el cap. 3 de Manus usa `ps aux`
  (E1/E4: leer USER para saber de quién es cada proceso).
- Mensajes/exit GNU-honestos: `ps: unknown option -- 'x'` exit 2; `ps: invalid
  option`; sin processos → cabecera sola (GNU no lista nada si no hay).
- `CommandSpec(name="ps", concepts={"ps"}, noise=NOISE_PROFILE["ps"])`.

**Hito S1.3 — comando `env` (same module):**
- `env` (solo-lectura): imprime `VAR=valor` por línea, ORDENADO por clave
  (codepoint → determinista; GNU env ordena por el entorno real, nosotros fijamos
  el orden para reproducibilidad). Sin flags permitidos de momento (didáctico:
  `env: invalid option` exit 2 si recibe `-*`); sin programas (`env VAR=...`)
  → rechazo *no soportado* con la voz del shell.
- `CommandSpec(name="env", concepts={"env"}, noise=NOISE_PROFILE["env"])`.
